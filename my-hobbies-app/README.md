# My Hobbies

A React + Vite recreation of the "My Hobbies" card design.

## Setup

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```
